6. GENRE-SPECIFIC INTERPRETATION
--------------------------------------------------
Drama and Comedy show relatively strong classification performance. Their F1 scores indicate that the model can identify these genres more reliably from poster-level visual information.

Action also demonstrates useful predictive performance, particularly in recall. This indicates that the model can identify many Action posters, although false positives remain.

Crime, Thriller and Horror are more challenging genres. Their visual characteristics can overlap with other genres, which makes fine-grained classification difficult.

Horror requires particular attention because a relatively strong ROC-AUC does not necessarily produce a similarly strong F1 score. This can occur when the model ranks examples reasonably well but probability thresholding is difficult under class imbalance.

7. MULTI-LABEL ERROR INTERPRETATION
--------------------------------------------------
CineVision AI is a multi-label classification system. A movie poster can therefore have multiple correct genres simultaneously.

For example, a poster can legitimately belong to Drama, Romance and Thriller at the same time. Therefore, a partial match means that the model correctly identified at least one true genre while missing or adding other genres.

10. MODEL LIMITATIONS
--------------------------------------------------
1. The dataset contains imbalanced genre distributions.

2. Some genres have considerably fewer training examples than others.

3. Movie posters may share visual characteristics across multiple genres.

4. Metadata-derived labels may not always correspond to visually obvious poster content.

5. Multi-label classification is more difficult than single-label classification because multiple labels may be simultaneously correct.

11. OVERALL CONCLUSION
--------------------------------------------------
The EfficientNetB0 transfer-learning model provides a meaningful solution for multi-label movie genre prediction from poster images. The model demonstrates useful ranking and classification performance across the eight target genres.

The visualization and error analysis provide additional evidence for understanding model strengths, weaknesses, false positives, false negatives and uncertain predictions.
